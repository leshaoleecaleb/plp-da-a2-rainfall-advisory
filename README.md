# County Rainfall and Planting Advisory

## Project Summary

This project analyses monthly rainfall data for five Kenyan counties: Nairobi, Nakuru, Kisumu, Mombasa and Machakos.

Python and NumPy are used to clean the data and calculate annual rainfall totals, monthly averages, wettest months, dry-month counts and recommended two-month planting windows.

## How to Run

1. Open rainfall_analysis.ipynb using Google Colab or Jupyter Notebook.
2. Run all notebook cells from top to bottom.
3. Install the required library using: pip install -r requirements.txt

## Planting Advisory

- Nairobi, Nakuru, Kisumu and Mombasa have April–May as their strongest consecutive two-month rainfall window.
- Machakos has November–December as its strongest consecutive two-month rainfall window.
- Treat these as preliminary recommendations and check current local weather forecasts and farm conditions before planting.
